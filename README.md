# halu-cup

麻雀大会「Halu杯」の記念大会（店の貸し切り・ゲストあり）のリポ。
いま公開しているのは、Halu杯の過去成績のページ（トップ）と、大会ごとの結果のページ（第20回・第5回 三麻）。
トップは https://syowstar-cyber.github.io/halu-cup/ 、第20回の結果は https://syowstar-cyber.github.io/halu-cup/yonma20/ 。
第5回 三麻Halu杯の結果は https://syowstar-cyber.github.io/halu-cup/sanma5/ 。
検索エンジンよけは、全ページの `noindex, nofollow` で行う。検索には載らず、URL を知っている人だけが開く。
説明の MD（README・`docs/`）と `gas/` は、`_config.yml` で公開サイトに出さない。GitHub のリポでは誰でも読める。
`robots.txt` と `.nojekyll` は置かない。`robots.txt` はサイトの一番上（`syowstar-cyber.github.io/robots.txt`）にないと効かない。`.nojekyll` を置くと `_config.yml` が読まれない。

## 過去成績のページ（トップ）

- 大会が終わったら、`index.html` のその年の見出しの下の一番上に1行足す（年が変わったら見出しも足す）。日付・正式名・優勝者の P番号・受け口（`data-api`）・結果詳細のアドレスを書く。
- 普段の回のキット（mahjong の `kai/`）の結果は、次の回をそこで開くと見えなくなる。結果詳細は、その回の結果を固定の表に写してからリンクする（第5回は `sanma5/`。2026-11-15）。

- 第5回の名前は、普段の回の受け口に残した回（`halu-2026-11-14`）の名簿から読む。その回を `purgeKai` で消すと、第5回のページとトップの優勝者は P番号に戻る。
- 次の記念大会で一式（`1857c3a`）を戻すときは、もとの幹部用ページ（`index.html`）と過去成績の置き場が重なる。そのとき置き場を決め直す。
