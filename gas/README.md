# 点数報告 API の配置手順（Google Apps Script）

サーバを借りずに、Google アカウントだけで動く。所要 10 分。ブラウザで人が行う（Claude は代行しない）。
ドライブは使わない（保存先はスクリプト プロパティ）ので、ドライブへのアクセス許可は求められない。

## 1. スクリプトを作る

1. https://script.google.com を開き、「新しいプロジェクト」。
2. 左の `コード.gs` の中身を全部消し、この階層の `Code.gs` の中身を貼り付けて保存（Ctrl+S）。
3. プロジェクト名を「halu-cup-scores」など分かる名前にする。

## 2. 報告キーを設定する

1. 左メニューの歯車「プロジェクトの設定」→「スクリプト プロパティ」→「スクリプト プロパティを追加」。
2. プロパティ `REPORT_KEY`、値は受付で配る4〜6桁の数字（例: `2410`）。保存。

このキーを知らないと点数を送れない。ページのパスワードとは別物なので、受付時に色紙と一緒に伝える。

## 3. ウェブアプリとして公開する

1. 右上「デプロイ」→「新しいデプロイ」→ 種類の歯車で「ウェブアプリ」。
2. 説明は任意。「次のユーザーとして実行」= **自分**、「アクセスできるユーザー」= **全員**。
3. 「デプロイ」→ 権限の確認が出たら自分のアカウントで許可する（ドライブの権限は要求されない）。
4. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/.../exec`）をコピーする。

## 4. ページに URL を入れる

`score/config.js` の `window.HALU_API = ""` の引用符の中に、コピーした URL を貼る。
`git commit` → `git push` で反映される。

## 5. 動作確認

`https://syowstar-cyber.github.io/halu-cup/score/` を開き、プレイヤーと半荘と点数を入れて送信する。
表に反映されれば完了。JSON の実体はスクリプト プロパティの `PLAYERS`（点数）と `LOG`（送信履歴・直近120件）。ページの「JSONをコピー」で丸ごと取り出せる。

## 直したいとき

- 点数の訂正: 同じプレイヤー・同じ半荘でもう一度送ると上書きされる。
- 取り消し: ページの「取り消し」ボタン（null に戻す）。
- 全消去: エディタで関数 `resetAll` を選んで「実行」。
- `Code.gs` を直したら「デプロイ」→「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」→ デプロイ。URL は変わらない。
