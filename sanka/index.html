3. 競技方式

  • 本田プロ＋P1〜P15 が1〜4卓、ゆうこママ＋P16〜P30 が5〜8卓で、それぞれ4半荘を打ちます
  • プレイヤーNo（P1〜P30）は事前にお知らせします。対戦表は8章のとおりで、同じ相手とは2度当たりません
  • 順位は4半荘の合計ポイントで決めます（計算は4章）
  • 参加者の上位6名が準決勝へ進みます

  • 決勝で決まるのは優勝・準優勝です。第3位以下は準決勝の成績（素点順）で決めます（6章）

4. ルール

Mリーグ公式ルールに準拠します。次の点だけ本大会独自のルールです。

東場は親連荘・テンパイ連荘なし

場面扱い
親が和了連荘せず、次の局は親が移ります
親が聴牌で流局連荘せず、次の局は親が移ります
本場和了で親が流れる場合は0本場に戻します。流局の場合は1本積みます

東場は必ず東1局から東4局までの4局で終わります。

南場は親の連荘あり

  • 親の和了・聴牌流局ともに連荘し、本場を積みます
  • 南4局で親がトップの場合、アガリやめができます

場決めなし

  • 予選は風牌のつかみ取りをしません。席順は対戦表のとおりです
  • 準決勝・決勝は1回勝負なので、席と起家は自動卓のサイコロで決めます

トビ終了なし（Mリーグと同じ）

持ち点がマイナスになっても半荘は終わりません（箱下あり）。予選・準決勝は規定時間まで、決勝は最後まで打ちます。マイナスの点棒は、そのまま点数報告ページに入れてください。

点数計算（予選）

項目内容
持ち点・返し25,000点持ち・30,000点返し（Mリーグ公式規定と同じ計算）
手順①（点棒−30,000）÷1,000 を出す。100点＝0.1ポイント（五捨六入などの丸めはしない）
手順②①に順位点を足す。1位 +50／2位 +10／3位 −10／4位 −30（ウマ30-10にオカ20を含めた値）
順位1〜4位は点棒の多い順
端数出ない。卓の合計は必ず0
同点同点の人で順位点を分ける（1位と2位が同点なら (50+10)÷2 で各 +30）。0.1で割り切れないときは起家に近い方が多く取る

例: 西家 40,000・東家 33,500・北家 28,100・南家 −1,600 のとき

→ 西 +10.0+50 = +60.0、東 +3.5+10 = +13.5、北 −1.9−10 = −11.9、南 −31.6−30 = −61.6（合計0）。ポイントは小数1桁で扱う。

予選の順位は、4半荘のポイント合計で決めます。点数報告ページに卓の4人の点棒を入れると、自動で計算されます。

準決勝・決勝も同じページで卓ごとに報告します。卓のメンバーは予選の順位から自動で表示されます（素点で順位を決めます）。
