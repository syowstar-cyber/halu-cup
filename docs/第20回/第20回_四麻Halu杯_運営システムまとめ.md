## 2. 仕組み

- ページは GitHub Pages（無料・サーバなし）。更新は `halu-cup/tools/rebuild.py` → commit → push。1〜2分で反映。
- 幹部用ページは、MDをHTMLにした平文ページ（2026-09-16 までは暗号化＋パスワード復号だった）。
- 打ち上げの希望日は、参加者ページのフォーム → Apps Script のスクリプト プロパティ `PARTY`（名前 → No・選択・時刻）。幹部用ページ8章は当日・翌週・不参加の表を出す（2026-10-16〜 `tools/template.html` の `PARTY_FIXED`。希望は直せない）。全消去は `resetParty`。送るたびに履歴を `PARTY_LOG` へ1件足す（時刻・名前・No・前後の回答。消す処理なし。`PARTY_LOG_1`… に分けて積み、今の番号は `PARTY_LOG_N`）。幹部用ページ8章の「回答の履歴」に出る（2026-10-08〜）。2026-10-16 にメンバーが決まり、参加者ページのフォームを閉じた（`tools/template_sanka.html` の `CLOSED`。当日・翌週のメンバーのページ `uchiage/` へのボタンだけを出し、送らない）。受け口は受けられるまま（直すときは `PARTY_FIXED` を false に戻すと、8章に希望の欄が戻る）。
- 出席者一覧（P番号 → 名前）はスクリプト プロパティ `ROSTER`。幹部用ページ8章の「出席者一覧の名前を直す」（たたんである）で登録・修正（`{action:'roster', names:{P1:'名前'}}`）。参加者ページ・幹部用ページとも読み込み時に受け口から取る。名前は主催の呼び名（LINE表示名ではない・2026-10-08〜）。名前を変えると打ち上げ希望も回答時刻ごと新しい名前へ移り、履歴に「名前を変更」と1件残る。大会後に名前を消す手順は `gas/README.md` の2d。
