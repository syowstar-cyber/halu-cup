## 越えない線（第20回で決めたこと）

- 参加者の名前はファイルに書かない。受け口の `ROSTER` だけ。変更履歴の行も P番号で書く（第20回 2026-10-24 に決勝の3名を名前で書いて公開し、公開リポの git 履歴に残った）。
- 金額（参加費・収支・ゲストの謝礼）はページにもMDにも書かない。
- 店の方への言い方: お借りする立場で書く（「〜をお願いします」）。主催が主・こちらが許可する言い方はしない。「スタッフ」と呼ばない。打ち合わせ相手の実名は載せない。同席した打ち合わせを「うかがいました」と書かない。
- ゲストの紹介の文言・所属の出し方・撮影と動画の扱いは、ゲスト側（団体）の回答と主催の指示に合わせる。Claude が決めない。
- `Code.gs` のデプロイは人が行う。Claude は代行しない。
- くじの数字が出た後は、型も計算も変えない。
- push は主催が頼んだときだけ（halu-cup は公開リポ）。
- 優勝の景品に金銭は一切出さない（2026-11-01 主催「徹底」）。
- ゲスト本人のこと（飲み物など）は公開リポに書かない。正典は保管庫 `Obsidian/60_暮らし/人物.md` の「友人・知人」（先に読む。ここへ写さない）。

## 手順（Claude が回すところ）

1. 前の記念大会の一式をタグで残す: 主催が頼めば `git -C halu-cup tag dai<N> <片付け前のコミット>`（第20回は `dai20` を `1857c3a` に）→ タグの push も主催が頼んだときだけ。
2. 片付けた部品を戻す: `git -C halu-cup checkout 1857c3a -- tools score rule fu renshu uchiage haichi.svg poster.jpg` → `git -C halu-cup status --short` に戻したファイルが並べば done。`kuji/`・`index.html`・`sanka/` はいま第20回の順位表とその入口（`sanka/` は参加者に配ったアドレス）＝順位表を残す場所を主催に聞いてから `git -C halu-cup checkout 1857c3a -- kuji index.html sanka`。
3. 戻した一式は第20回の大会後の状態＝初期に戻す: `tools/build.py`・`tools/build_sanka.py` の `ONLY` を `[]`／`score/lock.js` の `HALU_LOCKED` を `[]`／`tools/template_sanka.html` の `CLOSED` と `tools/template.html` の `PARTY_FIXED` を `false`／`tools/template.html` の `PARTY_SKIP` を `[]`／`kuji/seed.js` の `n4` を空／`tools/kuji.py` と `kuji/index.html` の `SWAPS` を `{}`。`kuji/semi.js` と `score/schedule.js` は第20回の結果＝新しい回の作りに合わせて作り直す。
4. `docs/第<N+1>回/` に正典MD3本を複製し、回の番号・日付・会場・ゲストを直す（mdio で書く）。`tools/build.py` と `tools/build_sanka.py` の `SRC` を新しい回に向ける。
5. `python halu-cup/tools/rebuild.py` → 最後の行が `OK index.html 更新` なら done。
6. 閉鎖したページを使う回は、`git -C halu-cup show faf220b:<パス>` で戻して直す。
7. 受け口（`gas/Code.gs`）を直したら `Code.gs` を主催へ送り、人がデプロイする。そのあと試し送信をして消す（日本語を含む送信は scratchpad の python の urllib で送る）。
8. 名簿は呼び名で `ROSTER` へ入れる（幹部用ページの「出席者一覧を貼り付け」か、python の urllib で送る）。名簿の正典は保管庫 `Obsidian/60_暮らし/` に置く。
9. 前日までに、予選→準決勝→決勝→順位発表を試しの点数で通しで動かし、手を入れずに次の段へ切り替わることを確かめる。本物の受け口へは送らない（模型で動かす形は `mahjong/.work/kai_test/` の `mock.js`・`e2e.py`）。
10. 大会が終わったら、まとめMD 0章に完了まとめ（結果は P番号）を書く。
11. 打ち上げまで全部のイベントが終わったら、主催が頼めば順位表だけ残して片付ける（第20回は 2026-11-01。中身はまとめMD 0章「片付けた後のページ」＝先に読む。ここへ写さない）。

- ゲスト・店・団体への連絡を Claude が送らない（送るのは主催）。
- 抽せんの後に型や計算を変えない。入れ替えは主催の判断で、ページに1行書いて知らせる（第20回の P6 と P14）。
