# 記念大会の手順書 — 店の貸し切り・ゲストありの Halu杯を、第20回の一式から準備する

正典（先に読む。ここへ写さない）:
- 第20回の全体（ページ・受け口・名簿の扱い・当日の使い方・更新のしかた・完了まとめ）＝`halu-cup/docs/第20回/第20回_四麻Halu杯_運営システムまとめ.md`
- 同じ内容を複数のページに書くときの置き場と、直す先の一覧＝同じまとめMDの5章「更新のしかた」

普段の回（組み合わせと点数だけ）は mahjong リポ。予選だけ・決勝卓だけで足りる記念大会なら、`mahjong/kai/` の方が軽い（`mahjong/docs/普段の回_手順書.md`）。
コマンドはワークスペース根（`tools/mdio.py` と `.claude` がある所）で打つ。報告は段ごとに `done`／`failed`／`skipped` の1行。指摘が無い段は「異常なし」と書く。

## 越えない線（第20回で決めたこと）

- 参加者の名前はファイルに書かない。受け口の `ROSTER` だけ。変更履歴の行も P番号で書く（第20回 2026-10-24 に決勝の3名を名前で書いて公開し、公開リポの git 履歴に残った）。
- 金額（参加費・収支・ゲストの謝礼）はページにもMDにも書かない。
- 店の方への言い方: お借りする立場で書く（「〜をお願いします」）。主催が主・こちらが許可する言い方はしない。「スタッフ」と呼ばない。打ち合わせ相手の実名は載せない。同席した打ち合わせを「うかがいました」と書かない。
- ゲストの紹介の文言・所属の出し方・撮影と動画の扱いは、ゲスト側（団体）の回答と主催の指示に合わせる。Claude が決めない。
- `Code.gs` のデプロイは人が行う。Claude は代行しない。
- くじの数字が出た後は、型も計算も変えない。
- push は主催が頼んだときだけ（halu-cup は公開リポ）。

## 手順（Claude が回すところ）

1. 前の記念大会の一式をタグで残す: 主催が頼めば `git -C halu-cup tag dai<N> <閉鎖前のコミット>`（第20回は `dai20` を `faf220b` に）→ タグの push も主催が頼んだときだけ。
2. `docs/第<N+1>回/` に正典MD3本を複製し、回の番号・日付・会場・ゲストを直す（mdio で書く）。`tools/build.py` と `tools/build_sanka.py` の `SRC` を新しい回に向ける。
3. `python halu-cup/tools/rebuild.py` → 最後の行が `OK index.html 更新` なら done。
4. 閉鎖したページを使う回は、`git -C halu-cup show faf220b:<パス>` で戻して直す。
5. 受け口（`gas/Code.gs`）を直したら `Code.gs` を主催へ送り、人がデプロイする。そのあと試し送信をして消す（日本語を含む送信は scratchpad の python の urllib で送る）。
6. 名簿は呼び名で `ROSTER` へ入れる（幹部用ページの「出席者一覧を貼り付け」か、python の urllib で送る）。名簿の正典は保管庫 `Obsidian/60_暮らし/` に置く。
7. 大会が終わったら、まとめMD 0章に完了まとめ（結果は P番号）を書く。

## この手順固有の禁止事項

- 第20回の `docs/第20回/` の中身を書き換えない（記録として残す）。新しい回は新しいフォルダに作る。
- ゲスト・店・団体への連絡を Claude が送らない（送るのは主催）。
- 抽せんの後に型や計算を変えない。入れ替えは主催の判断で、ページに1行書いて知らせる（第20回の P6 と P14）。
