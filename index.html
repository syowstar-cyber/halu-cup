4. ルール

Mリーグ公式ルールに準拠。以下が本大会の変更点。

東場は親連荘・テンパイ連荘なし

場面扱い
親が和了連荘せず、次局は親が移る
親が聴牌で流局連荘せず、次局は親が移る
本場和了で親が流れる場合は0本場に戻す。流局の場合は1本積む

東場は必ず東1局から東4局までの4局で終わる。親は全員1回ずつ。

南場は親の連荘あり

親の和了・聴牌流局ともに連荘し、本場を積む。南4局で親がトップの場合はアガリやめを認める。

場決めなし（席順は事前に決める）

どの半荘も場決め（風牌のつかみ取り）はしない。席順は事前に決めた対戦表に従う。

段階席順の決め方
予選4半荘対戦表に卓番号と席順（起家から）を4半荘分書いておく。プレイヤーNoの決め方は別途決める（ランダム抽選ではない）
準決勝S1卓・S2卓のメンバーは3章のとおり。1回勝負なので、席と起家は自動卓のサイコロで決める
決勝準決勝の結果で決まる4名。席と起家は自動卓のサイコロで決める

トビ終了なし（Mリーグと同じ）

持ち点がマイナスになっても半荘は終わらない（箱下あり）。予選・準決勝は規定時間まで、決勝は最後まで打ち切る。マイナスの点棒はそのまま点数報告ページに入れる（計算はマイナスに対応済み）。

点数計算（予選）

項目内容
持ち点・返し25,000点持ち・30,000点返し（Mリーグ公式規定と同じ計算）
手順①（点棒−30,000）÷1,000 を出す。100点＝0.1ポイント（五捨六入などの丸めはしない）
手順②①に順位点を足す。1位 +50／2位 +10／3位 −10／4位 −30（ウマ30-10にオカ20を含めた値）
順位1〜4位は点棒の多い順
端数出ない。卓の合計は必ず0
同点同点の人で順位点を分ける（1位と2位が同点なら (50+10)÷2 で各 +30）。0.1で割り切れないときは起家に近い方が多く取る

例: 西家 40,000・東家 33,500・北家 28,100・南家 −1,600 のとき

→ 西 +10.0+50 = +60.0、東 +3.5+10 = +13.5、北 −1.9−10 = −11.9、南 −31.6−30 = −61.6（合計0）。ポイントは小数1桁で扱う。

予選の順位は、4半荘のポイント合計で決める。点数報告ページに点棒を入れると自動で計算される。

5. 順位の決め方

決勝に進む参加者は2〜4名で変動する（本田プロ・ママが勝ち上がるかで変わる）。決勝で決まるのは優勝・準優勝だけで、決勝に第3位はない。

段階並べ方確定時刻
1位・2位決勝の参加者の上位2名（優勝・準優勝）決勝終了後（目安18:15）
3位〜6位それ以外の準決勝進出者（決勝で3・4番目だった参加者を含む）を、準決勝の素点順に決勝終了後（決勝の参加者が2名なら17:10）
以下準決勝に進めなかった参加者を、予選4半荘の合計ポイント順に15:20

打ち上げの振り分けに全30名の順位が必要。

下位の順位は15:20時点で確定するため、振り分け表の作成はそこから始められる。
